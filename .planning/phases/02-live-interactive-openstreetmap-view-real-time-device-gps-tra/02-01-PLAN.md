## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GPS Hardware Sensor → App State | Native Android location sensor data passes across platform channels into Dart UserLocation objects |
| Client App → OpenStreetMap Tile Server | Tile image requests dispatched to external OpenStreetMap CDN servers over HTTPS |
| Client App → Nominatim Reverse Geocoder | Coordinate reverse geocoding requests sent to Nominatim API over HTTPS |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | `UserLocation` / `LocationService` | medium | mitigate | Validate and clamp geographic coordinates (-90 to 90 lat, -180 to 180 lon); gracefully fall back to default Saidpur coordinates on invalid or out-of-range sensor readings |
| T-02-02 | Denial of Service | `MapScreen` / `TileLayer` | medium | mitigate | Throttle tile requests with local caching, set 3m distance filter on Geolocator position stream to prevent frame thrashing, rate-limit Nominatim requests to >=1100ms |
| T-02-03 | Information Disclosure | `LocationService.handlePermission` | medium | mitigate | Check runtime permissions explicitly using `Geolocator.checkPermission` and request non-blocking permissions; do not transmit raw GPS coordinates to unauthenticated endpoints |
| T-02-SC | Tampering | `pubspec.yaml` (dependencies) | high | mitigate | Package legitimacy check on `flutter_map` (^8.3.2) and `latlong2` (^0.10.1); verify official publisher on pub.dev (fluttermap.dev) and commit pubspec.lock |
</threat_model>
